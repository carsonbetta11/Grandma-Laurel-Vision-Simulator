# Grandma Laurel Vision Simulator

[Open the live page](https://carsonbetta11.github.io/Grandma-Laurel-Vision-Simulator/).

The site now serves the self-contained **An Illustrative View of Grandma’s Vision** room simulator supplied from the parallel Blender-rendered project. Its HTML is published unchanged as **index.html**, including all eight panoramas and the embedded TV and pharmacy-label artwork. No external assets, dependencies or build step are required.

## Controls

- Switch between **20/70 · left eye** and **Clear reference**.
- Drag or use the arrow buttons to look around; **Laptop**, **TV** and **Pills** center those objects.
- Adjust text size, page zoom, eye-to-laptop distance and email scroll.
- Optional reduced contrast and glare start off. Optional screen calibration and Reset are included as provided by the source project.

This is an illustrative model, not a clinical measurement of one person's vision. The webpage contains its own explanation and limitations.

## Hosting

GitHub Pages serves **index.html** from the root of **main**. The repository tracks only the page, this guide, `.gitignore` and `.nojekyll`. The Blender source scene, personal files and local QA assets are not uploaded.

The previous photo-only implementation remains recoverable in Git history at revision **294397d**. The parallel project's original source file is preserved separately on the Mac; future edits to it do not automatically update this repository.
